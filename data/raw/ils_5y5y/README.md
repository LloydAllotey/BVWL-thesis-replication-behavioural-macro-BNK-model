# 5y5y forward inflation-linked swap rate

This folder takes the Bloomberg export of `FWISEU55 Index` as an .xlsx file (monthly history,
fields `PX_LAST` and `PX_BID`, June 2004 to June 2026). Bloomberg data may not be passed on, so
the file is absent from the repository. The section Data of the main README describes the layout
that `build_database.R` expects.
